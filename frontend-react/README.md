# VascuAI frontend

Follow the [project setup guide](../README.md) for Node prerequisites, authenticated
backend setup, frontend commands and limitations. The current application uses React,
Vite and Oxlint; the initial scaffold and this directory's original introductory
documentation were React/Vite-template-derived.

Upstream references: [Vite](https://github.com/vitejs/vite),
[@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react),
[React](https://react.dev/), [Oxlint](https://oxc.rs/).
Dependencies retain their own licenses; see [attribution](../ATTRIBUTION.md).
No patient data, model weights, accounts or generated outputs are included.
